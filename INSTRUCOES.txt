=== BOT DE COBRANÇA VALE VERDE ===

Como usar o seu bot:

1. INSTALAÇÃO (Primeira vez)
- Baixe e instale o Node.js (https://nodejs.org) no seu computador se ainda não tiver.
- Abra o terminal (Prompt de Comando ou PowerShell) e navegue até a pasta 'ValeVerdeBot'.
- Digite o comando abaixo e aperte Enter para instalar as dependências:
  npm install

2. EXECUTANDO O BOT
- No mesmo terminal, digite:
  npm start
  (ou 'node app.js')

3. CONECTANDO AO WHATSAPP
- O terminal vai exibir um QR Code.
- Abra o WhatsApp no seu celular, vá em "Aparelhos Conectados" e leia o QR Code.
- A sessão ficará salva! (Sua conexão ficará guardada na pasta oculta gerada pelo whatsapp-web.js).

4. MENSAGEM
- O texto da mensagem está no arquivo: templates/cobranca.txt
- Mantive a sua mensagem padrão de forma dinâmica. As tags {{nome}} e {{valor}} serão automaticamente trocadas.

5. ARQUIVO EXCEL
- Coloque o seu arquivo 'Lista-fiado-05-08-26 1413.xlsx' na mesma pasta.
- O bot já está configurado para procurar por ele automaticamente.

6. RELATÓRIOS
- Após o envio, o arquivo de relatório será criado dentro da pasta 'reports' do projeto.
